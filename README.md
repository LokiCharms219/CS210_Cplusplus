# CS210_Cplusplus

Q - Summarize the project and what problem it was solving.

A - For this project, the client (Corner Grocer) needed a program to analyze text records of items purchased throughout a given day. The items are listed in sequential order from when the store opens to when the store closes. This grocery tracker illustrates how often items are purchased, allowing the store to be more efficient at merchadising their produce in the store. Writing a simple but easy to read UI file of the items purchased for a single day allows the program to output a list of all the items along with the number of times it was purchased that day, output the number a specific item was purchased that day, and output a text-based histogram, which lists all the items purchased that day and a representation of the number of times the item was purchased.

Q - What did you do particularly well?

A - While many people approached this project by merging Python and C++ together in Visual Studio, I decided to build on the Project 2 lesson on creating a header file and maintaining a minimal main file while creating a separate data file for main to pull the info from the txt input file. I feel, given my current level of programming knowledge, this was done very well and still got the job done given the requirements of the project.

Q - Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

A - I did institute some runtime error handling (creating an option 4 to exit the program should an exception be thrown) however I could write try/block statements to more easily handle errors.

Q - Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

A - The most challenging piece of code to write was the function to determine the frequency of a specific item. To overcome this, I broke down the code needed to list the number of times an item appeared. I utilized online resources outlined in the beginning of the week's project as well as the subreddit, Discord and other online resources like freeCodeCamp and Stack Overflow.

C++ is also the language used by many in the gaming indutry and I find it extremely beneficial learning this language for my future game modding adventures.

Q - How did you make this program maintainable, readable, and adaptable?

A - I applied industry standard and best practices. I used in-line comments to help highlight the functions of each block of code. I used appropriate naming conventions and kept the code in main to a minimum. I also wrote the code in a logical and easily readable manner.
